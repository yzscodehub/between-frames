屏幕空间反射（SSR）用当前相机已经画过的信息，继续寻找一次反射的来源。它不必重新查询每个场景图元，但能访问的数据也更有限：一张深度图通常只保存相机可见的第一层表面。

这一篇把 SSR 与完整几何查询并排放置。主相机输入来自**真实网格光栅化**，反射对照使用同一份展开后的三角形。默认用平涂颜色观察几何问题；所有视图共用同一个颜色模型。理解材质如何分配反射能量，可先看 [PBR 材质模型](/articles/pbr/)；理解第二条射线的构造，可回看 [RT04 单次光追反射](/articles/ray-reflections/)。

<h2 id="input">01 / 一张图，只有相机看到的那一层</h2>

本实验先把程序化网格画进 G-buffer：世界位置、几何法线和线性颜色分别保存，原生 DepthTexture 接收光栅化深度测试的结果。球体也使用屏幕中实际画出的低面网格，不换成一个更光滑的解析球来制造对照优势。

对于一个屏幕坐标，我们知道前层表面在相机轴向上的距离，也知道那个可见面的颜色。我们不知道它背后的第二个物体，不知道物体背面的形状，更不知道屏幕外还有什么。

默认平涂模型直接返回表面线性颜色。可选的局部明暗只使用固定方向，形式与 RT04 相同，不包含真实阴影、粗糙反射或间接光。镜面反射结果再乘地面的反射颜色。SSR 与完整几何必须同时更换模型，否则差异会混入着色变化。

<h2 id="ray">02 / 反射方向在三维中定义，再投回屏幕</h2>

相机射线先命中地面镜，得到位置 p 和几何法线 n。令入射单位方向为 d，理想反射方向为：

<Formula tex={'r=d-2(d\\cdot n)n'} />

起点沿几何法线偏移一小段，避免浮点误差立即碰回镜面。默认偏移是 0.001 世界单位；SSR 还排除起始镜面对象的深度层。这个排除只用于屏幕追踪的起始表面，并不让完整几何查询忽略所有同类物体。

三维候选点经过主相机投影，透视除法后得到 UV。只有 UV 在图像范围内、原生深度有效时，才执行比较。越界不会被夹到边缘纹素，然后假称找到了物体。

<Formula tex={'h=P_{\\mathrm{camera}}(q,1),\\qquad uv=\\tfrac12(h_{xy}/h_w+1)'} />

本文以相机前方的正轴向距离 −z 进行厚度判断。它与沿反射射线的 t 是两个量：即使方向已归一化，斜射线上的距离变化也不等于轴向深度变化。

检查面板来自一个小的 GPU 调试缓冲。每个记录都执行同一个选中像素的真实步进过程；编号只决定取回哪一步，不改变路径本身。它没有根据 CPU 轨迹补画所谓 GPU 路径，也没有把无数据的地方插值成已知深度。

<h2 id="sampling">04 / 实验二：固定三维步长，并不固定屏幕间隔</h2>

固定视空间步长实现直观：每次沿反射方向移动同样距离，再投影。透视会让这些点在屏幕上的间隔变化，因此既可能重复读取一个纹素，也可能跳过细条占据的纹素。

McGuire 与 Mara 的 [2014 年 JCGT 论文](https://jcgt.org/published/0003/04/04/paper.pdf)采用透视校正 DDA，让屏幕采样沿主轴前进。其关键是让 Q=q/w 和 k=1/w 沿屏幕线段线性插值，再用 Q/k 还原三维位置。本实验采用这个透视关系与主轴间隔，但使用单层深度跨越和二分细化；**不包含论文的多层版本、半纹素深度区间测试与抖动，不是完整移植。**

<Formula tex={'q(\\lambda)=\\frac{(1-\\lambda)q_0/w_0+\\lambda q_1/w_1}{(1-\\lambda)/w_0+\\lambda/w_1}'} />

屏幕间隔为 1 像素时，沿主轴逐个前进；较大间隔仍可能跳过细小结构。预算耗尽也会停止，所以“1 像素步进”并不保证有足够预算走完整条线段。

<h3 id="ssr-task-two">实验 2 / 细条消失，是步进太粗还是信息不存在？</h3>
<dl>
<dt>问题</dt><dd>固定视空间步长与透视校正屏幕步进，会怎样读取细条和背景之间的深度断层？</dd>

<dt>证据</dt><dd>比较实际样本 UV 的疏密、对象 ID、预算终止与完整几何结果。把步进错过数据和根本没有数据分开。</dd>
<dt>结论</dt><dd>提高采样质量能改进已有表示的搜索，代价需要用实际步数和当前展示计时判断。</dd>

<h2 id="crossing">05 / 先发现跨越，再让厚度决定是否接受</h2>

令光线轴距与纹素轴距之差为 Δz。光线从前方跨到后方时，粗步长的终点可能已经越过整个厚度窗口。若先要求终点落在窗口里，再尝试细化，这个真实的跨越就会被直接丢掉。

<Formula tex={'\\Delta z=z_{\\mathrm{ray}}-z_{\\mathrm{scene}},\\qquad 0\\leq\\Delta z_{\\mathrm{refined}}\\leq\\tau'} />

本实验先检测前负后正的变化，对区间执行八次二分，再重新检查投影、对象身份和厚度残差。只有没有前一个有效样本的孤立正值，才先用厚度窗口限制候选。

τ 是**轴向数值容差**，不是物体真的有这么厚。调得过小会拒绝离散深度附近的候选；调得过大可能把越过轮廓的射线错误地接受为前层表面。二分也只能细化深度表示中的跨越，不能证明它对应真实三角形交点。

<div className="ray-counterexample"><strong>反例：细条后方是一块远处的面。</strong><p>相邻纹素的深度可能突然跳变。一条射线可以因这种变化获得数值跨越，却没有撞上它声称命中的表面。检查 SSR 与完整几何的对象 ID，比单看一条平滑的深度曲线更有说服力。</p></div>

<h2 id="missing">06 / 实验三：增加步数，不能创造第二层</h2>

“悬空遮挡与后层”把一块遮挡板放在主相机与目标之间。板下仍可能存在镜面到目标的反射路径，但主相机只存了板或其他前层表面的深度。这个差异不是把步数加到 256 就一定能修好。

<h3 id="ssr-task-three">实验 3 / 看不见的数据会被更多步骤补回来吗？</h3>
<dl>
<dt>问题</dt><dd>反射目标离开主画面，或被前层挡住后，SSR 与完整几何查询为什么分离？</dd>
<dt>预测</dt><dd>完整几何光线若仍命中目标，参考中就会保留它；SSR 可能返回出屏、无深度，或者误读前层。</dd>
<dt>操作</dt><dd>载入“缺失的一层”，比较 SSR、完整几何与差异图。固定镜面像素增加步数，再横移目标或小幅转动相机。</dd>
<dt>证据</dt><dd>读取 SSR 终止原因与参考对象 ID，观察后层反射是否存在；用当前相机条件检查，而非沿用上一次的参考。</dd>
<dt>结论</dt><dd>搜索精度与信息范围是两件事。没有被存入当前 G-buffer 的表面，需要另一种数据来源才能访问。</dd>
<dt>边界</dt><dd>相机转动也会改变反射方向；出屏不等于目标一定仍在镜中，必须由完整几何查询核对。</dd>
</dl>
</section>

SSR 未找到可接受命中时使用固定环境颜色，并在分类视图中保留出屏、近面、无深度、距离与预算等区别。它不会把这些情况全部记为“没有物体”。主视图因此可能仍很平静，分类与逐步记录才揭示回退发生在哪里。

<h2 id="reference">07 / 对照验证了什么，还没有验证什么</h2>

完整画面对照从同一个光栅主命中点发出反射射线，在相同世界三角形中查询最近命中。默认平涂模式把着色差异移出诊断；局部明暗模式仍会受到 SSR 只能读取主相机所见面的限制。

选点后，独立 CPU 求交再次检查完整几何 GPU 光线的对象、位置与颜色。这个检查验证参考的几何查询，不代表 SSR 必须与它处处一致。差异图使用线性颜色的平均绝对差并放大四倍；镜面区域才是反射比较对象，非镜面复制同一源颜色，因此其零差异不能用来稀释 SSR 误差。本实验不报告全幅平均误差，也不把差图称作置信区间或无限精度真值。

界面区分 CPU 提交与 GPU 计时。四格模式同时绘制 SSR、完整几何、差异与分类，合计时间不能冒充单独 SSR 的性能。默认每格为 320×200，没有随机累积、时域补全或粗糙反射积分。

本篇只覆盖地面 y=0 的单次理想镜面反射。多层深度、屏幕护栏、环境贴图、完整几何追踪和时域方法都可以扩展可用信息，但每一种都有额外约定与代价。继续阅读 [TAA 时域重建](/articles/taa/)时，应保留同样的问题：历史到底提供了新信息，还是只把旧错误变得更稳定？
