一根细杆落在两个像素之间时，单个采样点可能看见它，也可能错过它。相机稍微移动，结果便会跳变。TAA 让不同帧观察不同的亚像素位置，再复用过去的信息。困难在于：过去的颜色还属于当前这块表面吗？把它带回当前像素后，究竟应留下多少？

本篇用真实网格光栅化的棋盘、斜线、细杆和有色刚体，依次检查三个问题：**静态抖动是否真的增加了不同观测 → 运动后历史是否仍然有效 → 稳定与细节如何交换。** 算法在 WebGL2 中执行，不把动画插值当成时域抗锯齿。

<h2 id="sampling">01 / 一个像素，需要对一片区域取样</h2>

理想的像素颜色与其覆盖区域内的光有关。一次光栅采样只观察这个区域的一处，细小几何和高频着色因此容易出现锯齿或闪烁。这里每帧在两个轴上使用小于半个像素的投影偏移，让采样位置发生变化。

实验采用 **16 点 Halton 循环**。抖动 j 的单位是像素；正 x、y 表示投影图像向右、向上移动，GL UV 从左下开始。对于宽 W、高 H 的透视投影，Three.js 所用矩阵中的对应系数变化为：

<Formula tex={'P^{\\prime}_{0,2}=P_{0,2}-\\frac{2j_x}{W},\\qquad P^{\\prime}_{1,2}=P_{1,2}-\\frac{2j_y}{H}'} />

这里行列从 0 数起。负号来自观察空间前方的 z 为负、裁剪坐标 w=−z；最终投影图像确实移动了正 j 个像素。降低分辨率时必须重新换算，不能把像素偏移直接当成裁剪空间位移。

**历史年龄不是独立 spp。** 本实验的第 17 帧会重复第 1 帧的抖动位置，历史还有重采样、拒绝和非均匀权重。年龄只描述这条有效历史链的长度，不能据此声称得到相同数量的独立超采样。

<h2 id="reprojection">03 / 几何验证 UV，与历史颜色 UV 不同</h2>

当前表面属于一个刚体时，先用当前物体变换的逆矩阵回到局部坐标，再用前一帧物体变换得到其前一帧世界位置。将该位置投影到前一帧相机，得到几何验证坐标 ug：

<Formula tex={'p_{t-1}=M_{t-1}M_t^{-1}p_t,\\qquad q_{t-1}=P^{\\prime}_{t-1}V_{t-1}p_{t-1},\\qquad u_g=\\tfrac12\\left(\\frac{q_{t-1,xy}}{q_{t-1,w}}+1\\right)'} />

P′已经含有**前一帧的抖动**。这份坐标用于读取那一帧真实光栅化的深度、法线和对象身份；不能再额外加一次前帧抖动。

但历史颜色储存在固定的输出像素网格上。颜色读取要移除纯抖动造成的位移，保留相机和物体的真实屏幕运动：

<Formula tex={'u_h=u_g+\\frac{j_t-j_{t-1}}{(W,H)}'} />

两个轴分别除以对应分辨率。在完全静止的场景中，ug 会随抖动移动，而 uh 应回到当前像素 UV。这样当前帧与过去帧观察不同亚像素位置，却在同一个输出像素中组合。面板同时展示 ug 和 uh，图中的橙点表示前帧**几何**坐标。

<details>
<summary>展开：为什么直接用几何 UV 读取历史会抵消静态采样？</summary>

用一维信号 f 表示静态场景。在图像正向偏移 j 的约定下，固定像素 u 得到的是 f(u−j)。前一帧缓存为 H₀(u)=f(u−j₀)。

若本帧直接到 u+j₀−j₁ 读取历史，便得到 H₀(u+j₀−j₁)=f(u−j₁)，它重新追到了当前采样位置，并没有保留原来的亚像素观测。使用固定网格坐标 uh=u，才会把 f(u−j₀) 与 f(u−j₁) 组合。本站 CPU 与 GPU 用例都包含这个高频阶跃反例。

</details>

<h2 id="validation">04 / 实验二：运动之后，谁还能接收历史？</h2>

在前帧坐标内并不等于找到同一个表面。刚体移开后，新露出的背景像素可能投到旧的有色物体上。本实现检查 UV 范围、稳定对象 ID、前帧轴距和世界法线；历史颜色的所有非零双线性邻居还需具有相符的历史所属对象。

深度比较使用同一个前帧相机空间：当前表面预测的前帧轴距，与前帧光栅记录的轴距相比较。不能直接拿当前相机的 z 去和旧相机的 z 相减。任何有效性条件失败时，历史权重归零、年龄重置为 1。

拖动帧号或打开分享链接，都会从第 0 帧重放至目标，不能把一个孤立帧伪装成已经拥有完整历史。改变权重、验证、约束或分辨率时，也会重建相同序列。播放速度取决于计算，不承诺 60 fps。

<h2 id="clipping">05 / 实验三：历史权重与 RGB 约束的取舍</h2>

验证通过后，仍可能留有采样误差、光照变化或不完美重投影。本实验在当前帧 3×3 邻域中计算 RGB 各通道的最小值与最大值，形成一个颜色包围盒，再把离群历史沿盒中心方向拉回边界。

令盒中心为 c、半宽为 e，历史颜色为 H。加入很小数值余量 ε 后，约束可写为：

<Formula tex={'m=\\left\\|\\frac{H-c}{e+\\varepsilon}\\right\\|_\\infty,\\qquad H_c=c+\\frac{H-c}{\\max(1,m)}'} />

随后用历史权重 w 与当前颜色 C 混合。本实验还用旧年龄 a 限制早期历史的比例：

<Formula tex={'w=\\min\\left(w_{\\max},\\frac{a}{a+1}\\right),\\qquad C_{\\mathrm{TAA}}=(1-w)C+wH_c'} />

历史被拒绝时直接令 w=0。权重上限为 0.95，不代表首个有效历史立即占 95%；例如旧年龄为 1 时，上式只能使用 0.5。面板显示实际 w，而不只显示滑块请求值。

<div className="ray-counterexample"><strong>反例：当前帧没有采到一根亮细杆。</strong><p>若整个 3×3 邻域都只看到暗背景，真实的亮历史可能落在颜色盒外，被约束压暗。它确实减少了波动，却也可能删除正确的细节。单看没有闪烁的截图，无法发现这种代价。</p></div>

本实验对背景不建立几何历史，并要求颜色双线性邻居的对象身份一致。这会保守地拒绝一些跨轮廓的历史，几何边缘可能继续闪烁；不能把内部棋盘噪声下降当作所有轮廓都已正确抗锯齿的证明。观察局部拖影与细节时也要看对应区域：全图平均误差可能被大片纹理的改善主导，未验证的历史甚至可能有更低的全图 MAE，却留下明显错误旧色。

<h2 id="reference">06 / 参考冻结的是同一帧，不是过去一段时间</h2>

“生成同帧 64 样本参考”固定当前相机和几何，使用另一组 8×8 分层的亚像素位置，各自重新光栅化，再在线性颜色中平均。它不使用 16 帧循环中的历史，也不会让移动物体在生成期间继续运动。

参考目标是固定像素覆盖区域的空间平均。取样偏移不会被偷偷改成当前抖动位置，以掩盖坐标错误。32 → 64 的平均变化只用于诊断剩余变化，不是误差上界。

生成期间锁定帧与物理条件，曝光和显示切换仍可查看已有内容；取消、恢复播放或载入其他条件会使旧请求失效。CPU 调度令牌阻止取消后的回调发布旧参考。仅生成或更新基准时读回整幅图像；普通选点只读一个很小的调试缓冲。

MAE、RMSE 比较全图所有有限 RGB 对，包括有效背景与轮廓：当前像素中心即使没有几何，64 个子样本仍可能覆盖细杆的一部分。面板记录有效比例与非法像素数，非法结果不能悄悄算成零误差。拒绝区域 MAE 也不是“拖影质量”的完整评分：它描述其中一组像素的颜色误差，还需要同时看局部结构。一次估计优于另一估计，不意味着以后每帧都会单调改善。

<h2 id="limits">07 / TAA 还不能替你补上哪些信息？</h2>

[SSR](/articles/ssr/)可能因屏幕外信息缺失而漏掉反射。时间重用可以保留以前看到的线索，但无法保证旧反射仍属于当前场景。本文只处理不透明的几何光栅信号，不声称已经处理反射运动、透明、多层遮挡、蒙皮或任意材质变化。

[低样本间接光重建](/articles/ray-denoising/)也利用历史和几何约束，但其目标是随机路径估计中的间接光 B。本篇的目标是像素区域内的空间采样；不能把两套年龄、误差或参考互换。

TAA 的采样累积与历史验证之分可参阅 [Yang、Liu、Salvi 的综述](https://research.nvidia.com/labs/rtr/publication/yang2020survey/)；工程背景还可参考 [Karis 的 SIGGRAPH 2014 课程](https://advances.realtimerendering.com/s2014/index.html)及 [Playdead 的公开实现](https://github.com/playdeadgames/temporal)。本站使用受控场景、16 点循环与简单 RGB 包围盒，不是完整 UE TAA、SVGF 或 TAAU。
