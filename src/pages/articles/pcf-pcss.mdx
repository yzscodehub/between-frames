硬阴影的边界可能是一串明显台阶。让它变平滑，有两种不同的目标：减少离散深度图造成的锯齿，或者近似面光源形成的半影。PCF 与 PCSS 分别提供了重要工具，但“看起来软”不足以证明二者在回答同一个问题。

本篇沿三个任务推进：**先比较再平均 → 让滤波范围跟随接触关系 → 用多层遮挡检验近似。** 这里讨论指定光源的直接可见性，不是 GTAO 所估计的周围环境局部遮挡。需要补充投影与偏移约定时，可先读[阴影贴图](/articles/shadow-mapping/)。

<h2 id="pcf">01 / 模糊深度，与过滤可见性并不等价</h2>

设某个样本存储深度为 Di，对应接收阈值为 τi。PCF 对每个样本先比较，得到可见为 1、遮挡为 0，再平均这些结果：

<Formula tex={'V_{\\mathrm{PCF}}=\\frac{1}{K}\\sum_{i=1}^{K}\\mathbf{1}[\\tau_i\\leq D_i]'} />

τi 已包含本实验的轴距偏移与可选接收平面修正。斜面上，不同样本的 τi 可以不同，不能始终拿接收点中心深度去比较整个窗口。

一个手算反例就能说明顺序为何重要：设两个存储深度为 0.3、0.9，接收阈值均为 0.5。先比较得到 0、1，平均为 **0.5**；若先把深度平均为 0.6，再比较，则得到 **1**。这不是舍入误差，而是比较这种非线性操作改变了结果。[GPU Gems 第 11 章](https://developer.nvidia.com/gpugems/gpugems/part-ii-lighting-and-shadows/chapter-11-shadow-map-antialiasing)同样把 PCF 定义在多次深度比较的结果上。

本文 PCF 使用等权 **9×9 固定格**。设半径 R 以纹素为单位，图宽为 N，样本请求位置为：

<Formula tex={'uv_{ij}=uv_r+\\frac{R}{N}\\left(\\frac{i}{4},\\frac{j}{4}\\right),\\qquad i,j\\in\\{-4,\\ldots,4\\}'} />

每次请求再落到实际纹素中心。半径小的时候，不同请求可能读到同一纹素；因此 **81 次查询不一定是 81 个不同纹素**。R=0 时全部读取同一位置，结果退化成同一个硬比较。

<h2 id="penumbra">03 / PCSS：先估计遮挡距离，再决定过滤范围</h2>

同一灯面下，遮挡物贴近接收面时，许多灯面点对应的阴影轮廓挤在一起；遮挡物离开接收面后，这些轮廓分开，形成较宽半影。PCSS 用一个代表性的遮挡轴距概括这种关系，再选择 PCF 窗口。

本实验先找出有效遮挡样本集合 B，逐个把透视深度 d 转回光源轴距 z，再平均：

<Formula tex={'\\overline z_b=\\frac{1}{|\\mathcal B|}\\sum_{i\\in\\mathcal B}\\frac{fn}{f-d_i(f-n)},\\qquad n=0.5,\\quad f=25'} />

**不能先平均原始透视深度再线性化。** 两者经过的是不同运算，得到的遮挡距离一般不相同；后面的相似三角形需要真实长度关系，而不是 [0,1] 深度编码。

界面的“灯面半边长”记为 sL，它是方灯在世界空间中的半边长度，不是直径、UV 半径或纹素数。用接收点轴距 zr 和平均遮挡轴距 z̄b，在平行层近似下得到世界半径，再换到 UV 与纹素单位：

<Formula tex={'r_w=s_L\\frac{\\max(0,z_r-\\overline z_b)}{\\overline z_b},\\qquad r_{uv}=\\frac{r_w}{2z_r\\tan(\\theta/2)},\\qquad r_{\\mathrm{texel}}=N\\,r_{uv}'} />

这是本站正方形透视光图的换算，不能省掉世界到 UV 的一步。最终 PCSS 仍使用 9×9 比较格，改变的是它的空间跨度。[NVIDIA 的 PCSS 白皮书](https://developer.download.nvidia.com/whitepapers/2008/PCSS_Integration.pdf)给出了搜索遮挡、估计半影、进行过滤的框架；本站的采样格与搜索近界另有明确简化。

<details>
<summary>展开：从相似三角形到一个可手算的半径</summary>

考虑沿光源轴排列的灯面、遮挡层与接收层。灯面边缘相对中心偏移 sL，经过位于轴距 zb 的遮挡边缘后，在 zr 处产生的额外横向偏移与 (zr−zb)/zb 成比例。由此得到 rw。接收轴距处，整幅光图的截面宽度为 2zr tan(θ/2)，除以它便得到 UV 半径。

例如 sL=0.5、zr=10、zb=8 时，rw=0.125。若 θ=75°、N=256，则 UV 半径约为 0.00815，纹素半径约为 2.09。这是说明单位换算的手算例，不是当前 GPU 的固定读数。

实际几何未必是平行层。接收平面修正会调整每次深度比较的位置，但这里的半影半径仍用接收点中心轴距与平均遮挡轴距。修正比较位置，不会让这个半径估计自动变成精确面积积分。

</details>

曲面上的局部平面也不能无限外推。PCF 或 PCSS 的样本在掠射方向上可能没有有效平面交点，或修正后的轴距超出 near/far；即使 UV 仍在光图内，也会显示橙色。可以关闭“接收平面修正”对照橙弧与自遮挡的变化，但这会重新承担斜面位置错配的误差，不是一次无代价的修复。

灯面半边长为 0 时，本实现直接回到中心硬比较；这避免把零面积灯面代入普通面积采样公式。即使灯面很小，深度图分辨率、偏移与固定采样格造成的误差也不会同时消失。

<h2 id="search">05 / 搜索窗口为什么不用投影近面直接代替？</h2>

在知道平均遮挡距离之前，必须先决定到哪里找遮挡者。直接让搜索范围从 n=0.5 的投影近面扩张，在本站这组已知小场景中可能浪费大量查询空间。我们利用 CPU 已有的完整投影几何，取所有投射阴影三角形顶点的最小光源轴距，并与投影近面约束合并，得到保守近界 z0。

搜索 UV 半径为：

<Formula tex={'r_{\\mathrm{search}}=\\frac{s_L\\max(0,z_r-z_0)}{2\\tan(\\theta/2)\\,z_0z_r},\\qquad z_0\\geq n'} />

这里使用 **81 个固定格点搜索**，没有从少量光图样本反猜 z0，也没有把第一个恰好命中的样本当成全场景最近遮挡者。几何变化时，这个已知场景边界需要更新。

<details>
<summary>展开：保守近界的依据，以及它没有保证什么</summary>

世界顶点变换到光源观察空间后，轴距是顶点位置的线性函数。三角形内部的位置是顶点的重心组合，因此它的最小轴距不会小于该三角形顶点的最小轴距。取所有相关三角形的最小值，再考虑近面裁剪，就得到该场景的下界。

对固定接收轴距，可能越靠近光源的遮挡层，需要考虑的横向灯面范围越大。把这个下界代入相似三角形关系，可给出搜索区域的保守跨度。它依赖本实验已知的场景几何，区别于白皮书示例中直接使用投影 near plane 的方式。

**区域保守不等于离散样本不会遗漏。** 81 个格点之间仍有空隙，细小遮挡者可能一个也没被采中；单层光图没有存下的后方几何，也不会因为扩大窗口重新出现。搜索或过滤窗口越界、接收平面修正无法提供有效比较时，本实现保留无效状态，不把这些样本算成光照畅通。

</details>

任务 **“3 · 单层深度的边界”**载入“多层遮挡”，用错开的薄板制造不同遮挡层。从主相机看到的层次不是光图的全部内容：光图每个纹素仍只保存光源中心方向遇到的第一层表面。

<h3 id="filtering-task-three">实验 3 / 多个遮挡层能用一个平均距离代表吗？</h3>
<dl>

<dt>结论</dt><dd>平滑不能替代准确；单层表示和平均距离近似需要用完整几何的同点可见性检验。</dd>
<dt>边界</dt><dd>这是一个点的比较，不是整幅图像的误差；有限参考自身也有残余变化。窗口越界或接收平面修正失效时，不报告有效的方法差值，曲面橙弧也不能仅归因于分辨率。</dd>
</dl>
</section>

<div className="ray-counterexample"><strong>反例：前层挡住光源中心，却没有挡住灯面边缘。</strong><p>前层之外的另一块薄板仍可能遮住边缘方向，但那块薄板未必出现在对应的中心光图纹素中。对已有深度增加采样或平均，不能恢复从未记录的那层几何。</p></div>

当搜索没有找到遮挡者时，PCSS 返回可见，是当前搜索的结果，不是场景完全无遮挡的数学证明。它可能真的没有遮挡，也可能是固定格漏过了小物体；先用单点几何参考区分这两种情况。

<h2 id="reference">07 / 三类证据，不要互相冒充</h2>

<div className="ray-table-wrap">
<table>
<thead><tr><th>检查</th><th>输入与目标</th><th>能够支持的判断</th></tr></thead>
<tbody>
<tr><td>CPU 光图纹素射线</td><td>同一个真实纹素中心，与同一组网格三角形独立求交</td><td>核对光栅 DepthTexture 的存储深度；先避开覆盖边缘</td></tr>
<tr><td>GPU 样本的 CPU 复算</td><td>使用已经读回的深度与阈值，再做比较和平均</td><td>核对计算与显示；不是独立的图像参考</td></tr>
<tr><td>CPU 单点面积参考</td><td>在方灯上均匀覆盖取样，与完整三角几何查询有限线段</td><td>估计选中接收点的面积平均可见率</td></tr>
</tbody>
</table>
</div>

对非零面积 A 的灯面，最后一项估计的是：

<Formula tex={'\\overline V_A(p)=\\frac{1}{A}\\int_A V(p,y)\\,dA_y\\;\\approx\\;\\frac{1}{1024}\\sum_{i=1}^{1024}V(p,y_i)'} />

参考点使用确定性、按面积均匀覆盖的序列，并保留 512 样本检查点。1024 与 512 的差是收敛诊断，既不是误差上界，也不是置信区间。几何使用与光栅网格相同的世界三角形；线段只到灯面采样点之前，灯后物体不应造成遮挡。参考自身的微小射线起点、终点容差，与光图中的轴向“深度偏移”是不同操作。

这个目标不包含 ρ、接收余弦、灯面余弦或距离衰减。硬阴影查询中心方向，PCF 过滤光图纹素，PCSS 近似面积阴影；它们与面积参考之间的差不能一概判成实现错误。

改变接收点、灯面或几何后，参考目标变化，需要重新生成。只改变过滤方法或光图分辨率时，同一世界点的面积目标不变。检查面板中的有效比较状态仍要单独看；橙色可能来自光图窗口越界，也可能来自接收平面修正失效，不能将它呈现为貌似可信的绝对差。
