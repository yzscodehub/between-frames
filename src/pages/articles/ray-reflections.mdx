看到镜面时，相机首先碰到的是镜子，镜子显示的却来自另一个方向。本篇只做一次理想镜面反射：相机命中镜面后，发出一条反射光线，再读取它遇到的表面颜色。

我们把 SSR、完整几何 RT 与镜像相机放到同一场景中。重点是它们获取反射信息的方式，不在这里引入粗糙反射或多次光传输。

<p className="ray-source-note">需要检查 SSR 自身的步进、深度交叉与失败状态，可先阅读<a href="/articles/ssr/">独立 SSR 篇</a>。本篇保留轻量的屏幕反射基线，重点核对完整几何反射；不同实验室的场景不能直接混作误差基准。</p>

<h2 id="direction">01 / 方向翻转，位置还在镜面上</h2>

令 d 为入射单位方向，n 为单位法线，镜面反射方向为：

<Formula tex={'r=d-2(d\\cdot n)n'} />

反射保留切向分量，翻转法向分量。第二条光线从第一次命中附近出发，需要与阴影查询一样处理自相交。法线、方向与位置都在世界空间中；方向已经归一化，因此返回的 t 可以按场景长度解释。

<h2 id="target">02 / 先统一“碰到以后显示什么”</h2>

如果一种方法读取带阴影的颜色，另一种方法返回未经光照的材质颜色，那么两幅图的差异就不只来自求交。第一步选择“自发光颜色”，让表面直接返回 ρ + Le，不随法线方向改变明暗，先确认镜中命中的是同一表面。这是几何诊断信号，不是改变了物理路径积分器。

第二步选择“共享局部光照”，三种方法再共用下面的确定性颜色模型：

<Formula tex={'L_{\\mathrm{local}}=L_e+\\rho\\left(0.18+0.82\\max(n\\cdot \\ell,0)\\right)'} />

其中 ℓ 是固定单位方向，ρ 是表面颜色，Le 是自发光。镜面的结果再乘其反射颜色。这里的系数用于稳定地显示形状；**它不是对面积光源、阴影或间接光的物理积分。** 把这个限制写清楚，才能把差异归因于反射查询。

SSR 读取相机看到的深度与局部颜色；RT 在完整实验几何中寻找第二次命中；镜像相机参考则把整个相机关于地面 y=0 反射，并只保留越过镜面之后的光线段。

<h2 id="screen">04 / 实验二：物体出屏以后，镜子还应该看见它吗？</h2>

SSR 沿反射方向前进，把候选点投回屏幕，与当前深度层比较。这里采用屏幕投影步进、深度厚度判定与二分细化。厚度只是补足单层深度表示的启发式，不是完整三维表面的真实厚度；本实现不宣称复现 DDA 或生产级 SSR。

屏幕空间追踪的根本信息边界，以及缺失时如何回退，见 [McGuire 与 Mara 的原论文](https://jcgt.org/published/0003/04/04/paper.pdf)。本实验用环境值作为未找到反射信息时的回退，并把它与真实命中区分。

<section className="ray-task" aria-labelledby="reflection-task-two">
<h3 id="reflection-task-two">实验 2 / 离开画面，是否等于离开反射？</h3>
<dl>
<dt>问题</dt><dd>当被反射物不再由主相机直接看见时，SSR 与 RT 会发生什么？</dd>
<dt>预测</dt><dd>只要反射光线仍碰到该物体，完整几何 RT 会保留反射；SSR 可能出屏、缺少深度或落入回退。</dd>
<dt>操作</dt><dd>保持场景静止，缓慢改变相机，观察目标接近主画面边缘时的镜面区域；同时查看镜像相机参考。</dd>
<dt>证据</dt><dd>对照 SSR 图中缺失或退回环境的区域、RT 第二次命中和镜像相机图像，归因信息缺失。当前界面没有 SSR 逐步追踪或失败掩码，RT 路径日志不能替它解释每一步。</dd>
<dt>结论</dt><dd>完整几何查询能访问主相机不可见的数据；SSR 增加搜索精度也无法创造缺失几何。</dd>
<dt>边界</dt><dd>主相机转动同时会改变反射方向，并非所有出屏物体仍应留在镜中；必须用当前参考核对。</dd>
</dl>
</section>

<h2 id="path">05 / 实验三：一条反射究竟做了几次求交？</h2>

先找出镜面上的一个像素，再沿调试记录查看主射线与反射射线。命中位置、出发位置、方向、图元身份和终止原因来自实际 GPU 输出。镜面反射颜色作为第二段路径的权重出现，它不是新的自发光。

<section className="ray-task" aria-labelledby="reflection-task-three">
<h3 id="reflection-task-three">实验 3 / 屏幕里的反射颜色来自哪里？</h3>
<dl>
<dt>问题</dt><dd>能否从第二条光线的命中解释一个镜面像素？</dd>
<dt>预测</dt><dd>主射线命中镜面，第二段沿反射方向到达另一个表面；未命中时使用环境值。</dd>
<dt>操作</dt><dd>选中镜面内部像素，逐事件查看起点、方向、命中、权重与终止原因；再小幅调整相机，重新选中一个镜面像素检查。</dd>
<dt>证据</dt><dd>核对反射方向满足公式、起点靠近主命中且有数值偏移，返回颜色对应第二个表面的局部模型。</dd>
<dt>结论</dt><dd>镜面反射把两个可验证的查询连接起来；图像与逐事件记录应解释同一条路径。</dd>
<dt>边界</dt><dd>本篇只追踪一段反射；第二个表面即使也是镜面，也不会因此自动产生无限多次反射。</dd>
</dl>
</section>

<h2 id="limits">06 / 只对模型覆盖的现象下结论</h2>

SSR 还会受到深度分辨率、薄几何、厚度阈值和主视角表面信息的影响。RT 则仍受几何精度、偏移、查询范围和浮点数约束。两者的错误来源不同，不应把全部差异概括成“一个模糊，一个准确”。

本篇没有粗糙反射积分、材质多层、折射或完整全局光照。默认相机也不做亚像素抖动；单次镜面查询是确定性的，提高 spp 不会让其几何轮廓获得超采样抗锯齿。完整操作入口是<a href={rayLabHref('reflections',{learning:{article:'ray-reflections',chapter:'screen'}})}>光追反射实验室</a>。
