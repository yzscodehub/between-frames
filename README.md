# 一帧之间 · 交互式实时渲染

中文交互式实时渲染博客，当前包含 GTAO、阴影贴图与 PCF/PCSS、PBR、SSR、TAA，以及七篇 GPU 软件光追文章。正文、运行 Shader、检查读数和独立参考相互对应；长期选题不等于已完成文章。

## 本地运行

需要 Node.js 22+ 与 pnpm 11.19.0。依赖版本固定在 package.json，完整解析固定在 pnpm-lock.yaml。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开终端显示的地址（默认 http://127.0.0.1:4321）。

```sh
pnpm test          # 独立数学、状态和坐标测试
pnpm check         # Astro / TypeScript 检查
pnpm build         # 静态构建至 dist/
pnpm preview       # 预览构建产物
```

浏览器验收要求已有 Chrome，并先运行开发或预览服务器：

```sh
CHROME_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" pnpm test:browser
# 可用 TEST_URL 指定预览地址。
```

在没有全局 Node 的当前 Codex 环境中，可将下面的目录加入 PATH：
`/Users/zhou/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/bin`

## 实现组织

- `src/shaders/ao.glsl`：GTAO、教学 SSAO 和 HBAO 思路的硬半径教学实现。调试分支与显示分支共用切片、样本计算。
- `src/lib/renderer.ts`：Three.js 生命周期、模式、检查读回、固定参考与统计。
- `src/shaders/reference.glsl`：解析形状求交的余弦加权完整几何参考。
- `src/lib/math.ts`：独立数值积分，以及供二维实验使用的解析表达式。
- `src/lib/state.ts`：版本 2 分享状态和输入检查（版本 1 的旧几何链接明确回退新版默认场景）。
- `src/components/ShaderExcerpt.astro`：构建时从运行 GLSL 中提取标记代码。

React 只处理控制与读数，不驱动逐帧循环。实验动态加载、按需渲染；不可见时停止渲染。销毁释放观察器、事件、几何、材质及纹理。

## 数值约定

- AO 是可见度，1 完全可见、0 完全遮挡。
- 普通 WebGL 深度 [0,1]，观察空间相机朝 −Z。
- 半径使用世界/观察空间单位，硬半径截断，无额外强度、幂次或距离渐变。
- 切片角围绕视线定义，先裁剪至法线正半球，按 `cos(theta-gamma) * abs(sin(theta))` 积分，并乘回法线投影长度。
- 单切片贡献不裁剪；平均后才限制完整 AO 至 [0,1]。
- 默认测试台场景，4 切片 × 2 侧 × 6 步；固定种子 17。屏幕半径最多 150 像素。
- 空间滤波是 5×5 深度与法线引导滤波，不包含时间积累。

## 模式与参考

自由探索可旋转相机；单点检查冻结相机，跟随选中表面的局部位置。相同场景抬升物体时保留选择；点失去可见性时退出检查。

固定基准恢复标准相机及初始物体位置，分辨率 320×200。参考使用 1024 个余弦加权半球方向，32 样本一批，并保存 512 样本检查点。改变半径清除参考；改变几何或退出基准时清除参考及误差。切换算法、样本数或滤波重新计算对比指标，参考几何不变。

统计 MAE、RMSE 和 512→1024 平均变化。统计对象由滤波开关决定，与当前显示视图独立；背景像素不计入。

参考是解析平面、盒体和球体求交，并非通用场景光追器。球体可视几何为 96×64 细分网格，和解析球略有差别。参考读取和实时算法相同的位置/法线缓冲，但射线起点偏移与屏幕空间深度偏移不是同一操作。512→1024 变化仅是收敛诊断，不是误差上界。

## 已知教学简化

- 屏幕深度只包含第一层可见表面。出屏信息不能通过增加样本恢复。
- 切片方位按屏幕角均匀分布，在偏离屏幕中心处不是严格绕视线的均匀采样。
- 无厚度启发式、深度 mip、时间重投影、多次反弹补偿。
- SSAO 是余弦半球候选点的深度比较基线，不是方向射线可见性的无偏估计。
- 调试图若在 SSAO 模式显示 GTAO 切片，会明确标注为辅助图；样本判定仍来自 SSAO。
- AO 的 CPU 时间只显示几何/AO/滤波提交成本。AO 的 GPU 时间未测量，不用 FPS 代替。
- 单点检查依赖浮点颜色缓冲；能力不支持时降级为静态说明和重试。
- 分享参数恢复确定性初始状态，不保存 GPU 纹理或任意运行历史。分享单点检查会恢复为自由探索，接收者重新选点。

## 改进版实验

- 四个带观察任务的预设：接触、噪声、薄板、室内阅读角。高级参数默认折叠。
- 六个场景，全部由同一份球体/盒体规格创建实时几何和参考求交数据；最多 24 个盒体。
- 三种算法共享同一几何缓冲、相机、随机种子、半径和样本预算，单个 WebGL 上下文分四格显示。右下角固定为完整几何参考，未生成时占位，不用无 AO 替代。
- 支持统一材质或纯 AO 对照；后者才直接对应可见度数值。HBAO 教学版的目标角域测度不同，参考差异不能直接当作实现错误。
- HBAO 思路实现保留 `sin(h) - sin(t)` 角域累计，采用本文硬半径和共享搜索，不宣称等价于原始 HBAO、HBAO+ 或生产质量版本。
- 局部放大直接读取当前显示画布。比较模式同步放大三个算法与参考中的同一推荐区域，其他模式放大推荐位置或选中点。
- 调试缓冲现在输出实际样本表面位置与 SSAO 候选点。局部三维投影可旋转，切平面明确标注为解释几何。
- 新增二维地平线逐步实验：落地矩形与悬空薄板，逐样本更新边界；精确矩形角域显示单一地平线丢失的空隙。
- 常规显示分辨率跟随视口（DPR 最多 1.5、宽最多 1280）；固定基准仍为 320×200，避免参考比较条件漂移。
- HBAO 原始资料：[NVIDIA SIGGRAPH 2008 slides](https://developer.download.nvidia.com/presentations/2008/SIGGRAPH/HBAO_SIG08b.pdf)。

## 教学流程与一致性优化

文章内的 GPU 实验按章节分工：`profile="contact"` 只观察抬升与关闭 AO；`profile="sampling"` 固定为 SSAO，直接检查候选点。完整算法、参数、基准仍在实验室。新的 `ContributionExplorer` 固定可见角域，比较不加余弦的测度、解析加权贡献和独立数值积分，说明法线投影与权重的作用；详细推导按需展开。

实验链接可携带 `learning.chapter/lesson`，用于保持任务与返回原章节。只接受固定枚举，不接受外部返回地址。跨场景的完整状态恢复与手动换场景分开，分享中的相机不会被默认值覆盖。

局部观察由场景推荐点或选中表面点驱动。三算法与参考同时标出并放大同一像素区域；局部 MAE 对应该区域内的有效像素。参考面板固定身份，未生成时显示空位，不用“无 AO”顶替。推荐点被遮挡或出屏时明确提示。

最近纹素深度重建现在统一使用纹素中心，避免用连续 UV 配最近深度产生离面位置。地平线使用采样实际方位与名义切片之间的角度修正；调试 `value` 表示校正后地平线余弦。SSAO 候选 q 的连续投影与采样 UV 允许相差半个像素。CPU 解析平面测试与实际 GPU 测试分别验证数学约定和实际数值精度。

算法、滤波、预算或几何改变时，旧指标立即失效；暂停时显示等待重新计算，单步或恢复后再给出指标。屏幕高亮与样本面板共享一个组号/样本号，重新计算不会跳回第一个样本。切片视图覆盖完整合法角域。

- `/labs/ray-effects/`：方光源面积可见度、中心光图/PCSS，以及 SSR/单次镜面/镜像相机对照。
- `/labs/path-tracing/`：有限 Lambert 路径、GGX NDF 采样、BSDF/NEE/MIS、RR、间接光 B 的历史重建与三遍 à-trous。

七篇文章位于 `/articles/ray-intersections/`、`ray-bvh/`、`ray-shadows/`、`ray-reflections/`、`path-tracing/`、`ray-mis/`、`ray-denoising/`。每篇包括三个带预测、操作、证据与边界的实验任务；源码通过 `RuntimeSource.astro` 从实际内核提取。

### 计算和状态约定

查询统一世界空间与归一化方向，距离区间显式给定。几何法线、着色法线、正反面、图元 ID、对象 ID 和材质 ID 分开保存。当前不用法线贴图；场景使用显式三角形与解析球，不抽取 AO 高细分网格。CPU 原始求交使用独立平面/Gram 重心法，GPU 三角形使用 Möller–Trumbore。GPU 球体用最近接近点法避免远处小球判别式抵消，CPU 球体保留独立双精度二次方程求解。BVH 分布实验默认 512 个显式三角形；原始混合图元场景另供求交压力验证。

Worker 构建不可变快照、BVH 和纹理数据，一起提交；generation 屏蔽过期结果。上传包围盒额外包含 Float32 量化后的几何，并向祖先传播，防止上传后边界缩小漏掉实际图元。最大 2048 图元、4095 节点、深度 32、栈 64、每叶最多 4 图元。失败状态不会当作未命中。调试日志另限 256 个 BVH 事件或 8 个路径事件，日志截断不终止实际查询。

默认图像 320×200，低档 160×100，每更新 1 spp。方向采样使用可按像素/帧/样本/维度复现的计数式随机数。默认最多 2 次 BSDF 散射，可调至 8 次；预算用完后仍查询终点发光或环境。RR 在第三次散射后且仍有预算时执行，存活除以概率。NEE 不增加散射计数；MIS 对连续立体角 PDF 使用 power heuristic 2，delta 事件独立处理。

R7 接收面全部为 Lambert，直接生成第一表面设白的 B，而不是除以可能接近零的反照率。间接至少再经过一次表面散射；直接层另用 16 个灯面样本，合成 `Le + direct + rho * B`。历史使用对象 ID、前后位置/深度、法线验证，有效年龄上限 32，并对亮度突变降权。几何一致仍不保证间接光有效，残留拖影是教学边界。

连续受控相机或单刚体运动时重投影；相机切换、质量、拓扑、材料、光源、积分器等变化清空。R7 0–120 帧可确定性重放。曝光和中间视图仅呈现缓存。生成高样本参考时冻结当前帧；恢复运行、修改计算目标或主动取消都会使旧参考失效。分享只保存版本化参数与初始条件，不保存 GPU 纹理；R7 链接从零重放至指定帧。

### 对照口径与限制

- R3 比较的是光源面积可见比例，不是辐照度。中心光图通过同一 GPU 查询生成深度，PCSS 是单光图教学近似；未覆盖光图区域标橙色，不能用这套实现评价真实光栅阴影性能。
- R4 先共享自发光颜色 `rho + Le` 核对几何，再共享局部模型 `Le + rho * (0.18 + 0.82 max(n·l,0))`。它只用于形状与反射求交对照，不是 PBR；镜像相机参考限定 y=0 地面。SSR 无信息时回退环境，不代表真实未命中。
- R5/6 都是有限路径目标。高 spp 不恢复预算外光路，默认相机固定像素中心，不能把路径噪声收敛当作抗锯齿。
- MIS 主实验固定黑环境与一个矩形发光面。GGX 是单散射、NDF 半向量采样，不是 VNDF 或多重散射补偿；理想镜面不填伪连续 PDF。
- R7 当前只支持低面数场景、受控相机和一个平移刚体，每帧 CPU 重建 BVH。没有 refit、TLAS/BLAS、形变、体积、折射、ReSTIR、神经降噪或硬件光追后端。
- 参考图使用独立种子、1024 样本，并保留 512 样本检查点。MAE/RMSE 在线性数值有效区域计算；512→1024 变化是收敛诊断，不是正确性证明或误差上界。原始求交与光输运另有独立验证。
- 普通交互只读回选点小缓冲。全图数值统计只在用户生成/更新参考基准时读取。CPU 构建/上传提交/渲染提交与异步 GPU timer 分开；不支持或发生 disjoint 时显示不可用。调试读回和比较图生成不计入正常内核的 GPU 时间。
- 等 spp 不等于等成本。逐样本面板列出实际相机、延续、阴影射线与节点/图元测试；这些是所选样本的工作量，不能当作整帧总数。

## 第三批 · PBR → SSR → TAA（待统一人工审核）

| `/articles/taa/` | `/labs/taa/` | 固定输出栅格的时域估计，与冻结同帧的 64 次亚像素光栅参考 |

PBR 与 RT06 共用 `src/shaders/pbr/brdf.glsl` 的 GGX D、Smith G1、Schlick F。采用本站既定 alpha=roughness²、G=G1(V)G1(L)，没有把 PBRT 的不同参数化直接混入。D 分母使用数学等价的稳定形式，避免低粗糙度峰值处的大数抵消。新材质工作流使用常见的漫反射耦合近似，极端白色掠射时可能增能，积分结果不会被夹到 1；它不是全域严格守恒或完整 IBL。三球大小一致但透视下 V 不同，因此是定性比较；定量核对固定 N/V/L 或 NoV。

SSR 从真实光栅的 MRT 与原生 DepthTexture 查询，提供视空间固定步长和屏幕主轴步进。屏幕步进对 Q/w、1/w 做透视校正，先发现交叉再细化和检查轴向厚度。它是单层深度的教学实现，不宣称完整复现论文的区间处理、多层或生产 SSR。完整几何对照复用已验证的查询内核与同一批显式三角形，默认使用相同的平面颜色诊断。屏幕外、遮挡后层、预算耗尽与实际命中分别显示，不将所有缺失混作未命中。

TAA 使用真实网格光栅、16 点 Halton 循环、受控相机或刚体运动、对象/深度/法线验证、双线性历史颜色和 3×3 RGB 约束。几何验证 UV 包含前帧抖动；历史颜色 UV 再补偿当前/前帧抖动差，使静态场景在固定输出栅格上积累不同子像素样本。两类 UV 都可检查。曝光、视图只呈现缓存；策略变更、定位与分享从第 0 帧确定性重放；第 60 帧切相机清历史，第 120 帧停止。64 样本参考冻结同帧，独立取样，不混合运动前后帧；没有参考时参考和差值面板均为空位。

TAA 的统计包含全图有效 RGB（含背景/轮廓），非法像素单列；保守身份验证和背景无几何历史仍可能阻止部分边缘积累。初始运动基准显示：未验证历史可以得到更低的全图 MAE，却留下明显局部拖影。全文明确要求同时检查局部显露与细节，不宣称所有验证策略都会让单次或全图误差降低。

## 批次 C · 颜色基础、IBL、透明与 WBOIT · 2026-10-07

新增 `/foundations/color/`、`/articles/ibl/`、`/articles/transparency/` 和两个同实现实验室 `/labs/ibl/`、`/labs/transparency/`。当前共 15 篇技术文章、3 份基础说明、10 个实验室、6 条学习路线，六个主题均有内容；静态构建 45 页。新增“从线性光量到最终颜色”路线，PBR 按需补充颜色基础，原 URL 和状态协议保持兼容。

### 计算目标与工程边界

- 颜色基础使用 TypeScript + HTML/CSS 演示分段 sRGB 编解码、线性混合、曝光与 Reinhard；明确标为原理与数值实验，不称作 GPU 读回。黑白中点线性值 .5 对应编码约 .73536；直接平均编码 .5 对应线性约 .21404。
- IBL 的白 Lambert 与 F0=.04 单散射 GGX 分开显示。GGX 复用现有 PBR GLSL，alpha=roughness²、分离 Smith G1 乘积。直接 GPU 方向积分为 256 样本；环境为程序化方向函数，无外部贴图或模型。
- IBL GPU 预滤波采用 7×64×32 RGBA16F 经纬图集：六层 roughness=.20/.36/.52/.68/.84/1，加一层 Lambert。环境变更重建，粗糙度变更复用；层内双线性、层间线性插值。镜面预滤波使用 N=V=R 的近似。BRDF A/B 在片元内积分，未缓存 LUT，不以本演示时序宣称生产 IBL 加速比。经纬接缝夹取、低分辨率与有限样本均明确披露。独立 CPU 用均匀立体角序列和 Smith lambda 形式，32,768/65,536 两档只验证选中点。
- 透明实验使用三张有限平面、正交投影、线性颜色。对象中心顺序 over、GPU 逐像素三元素排序参考和 WBOIT 同屏。CPU 独立射线/平面求交后排序。精确相同深度按稳定 ID 决定次序；GPU/CPU 浮点精度不同，基准避开交线与外轮廓，不将其差异解释为一般算法误差。
- WBOIT 实际执行 RGBA16F 加权颜色加法混合和透过率乘法混合，再合成；不依赖每附件独立混合，采用两遍透明绘制。权重为 max(.01,(1-z)^p)，是公开说明的教学选择，不是论文完整工程权重。alpha=1 的颜色混合偏差保留为必须展示的反例。未实现折射、体积或与不透明深度的生产管线集成。

两套实验使用 `#ibl=` / `#transparency=` 版本化状态。按需渲染、离屏停止、暂停改单步、任务重置、分享恢复与重试均可操作。选点只读取小缓冲，正常交互没有全屏同步读回；没有可靠 GPU 时间时明确不提供，不拿 CPU 提交或 FPS 替代。曝光仅显示缓存并保留已有独立参考；影响计算目标的修改取消旧参考。实际捕获的文章图和条件在 `public/images/reading/lighting-provenance.json`。

## P1 后续交付：阴影迁移、CSM 与 HDR · 2026-10-07

本批实际完成三项：旧阴影贴图/PCF/PCSS 实验切换原生 WebGPU；新增 `/articles/csm/` 与 `/labs/csm/`；新增 `/articles/hdr/` 与 `/labs/hdr/`。当前为 17 篇文章、3 份基础说明、12 个实验室。原有十个实验室中 4 个完成迁移，新 CSM/HDR 从一开始即使用 WebGPU；不能把这两个新实验算进旧实验的迁移分母。

阴影迁移保留原网格、光源/相机、深度比较、81 点搜索及过滤、接收平面修正和旧分享格式。光源与相机都真实光栅化；相机 G-buffer 使用两个 RGBA32F 附件（32 bytes/sample），颜色经稳定对象 ID 查询存储缓冲，避免超出基础附件带宽限制。裁剪深度显式从原 GL 相机矩阵转换到 WebGPU [0,1]；纹素中心 UV 与读回语义保持原约定。几何法线来自实际片元导数。地面网格的展示分支保留导数，并局部关闭 WGSL 导数一致性诊断；阴影比较和检查日志本身不依赖这些导数。检查使用 332 个 vec4 的异步存储缓冲，保留过期读回拦截。

CSM 使用四张方向光深度图，混合分割、包围球拟合、接收区间重叠、世界纹素对齐和 3×3 PCF。偏移随级联世界纹素与接收斜率变化，保留漏光取舍。CPU 检查角点覆盖、分割和权重；GPU 实际读取距离、级联、权重与可见率。固定光源轴向范围只承诺当前有限展厅和受限相机，不是任意大世界 caster 拟合。默认标准档每级 2048²，低档 1024²。

HDR 使用展厅真实 RGBA16F 输入，半分辨率 2×2 提取、五抽头水平/垂直滤波、线性合成，再曝光/Reinhard/sRGB。错误顺序分支先映射再相加，输出明确标为已映射信号。实际合成点读取三个小缓冲；滤波另用常量与脉冲输入核对，不用截图冒充数值参考。主着色和 Bloom 阶段 GPU 时间分开，均不代表整帧。当前 HDR 展厅仍使用单图阴影，CSM+HDR 的统一场景整合、庭院与法线贴图仍待实施，P1 不标为全部完成。

新状态包含版本、场景/资源版本、相机、固定种子/帧号、质量档与参数。新任务支持暂停改单步、重置与分享；异步选点同时检查条件修订号与请求序号。无 WebGPU 时保留实际场景的静态预览和明确说明。
