默认低/标准/高档为 960×540 / 1280×720 / 1920×1080，受输出尺寸限制；资源预算 192 / 384 / 768 MiB。标准档 M2 目标为中位帧 16.7ms、P95 33.3ms，不把目标当测量结果。

迁移前源码与验证归档位于 baseline-2026-10-07；文件添加 .snapshot 后缀，避免被当前 TypeScript 编译。源路径和 SHA-256 在 manifest.json 中。真实适配器记录位于 test-results/webgpu/adapter.json（Apple / metal-3，非 fallback）。这只是能力检查，尚非性能或算法验收。

当前未请求外部读者参与，也未完成真人试读。不得将本记录的“未开始”主题展示为已交付文章。


P0 实际证据：115 项单元测试；30 个 PBR WGSL/CPU 配置检查；30 组 WebGL2/WGSL 配对读数；PBR 10 组 UI 回归；IBL/透明 11 组 GPU 与交互回归。PBR、IBL 设备丢失重试通过，快速检查与销毁后资源登记归零。测试使用默认 Chrome 的真实 Apple / metal-3 适配器。原测试强制 SwiftShader 参数会使此环境无法获取 WebGPU，已从迁移实验的测试启动参数移除。

P1 透明迁移已通过相同的独立 CPU 合成、半精度累积、顺序反转与高 alpha 反例验证。随后已完成阴影迁移及 CSM、HDR 独立文章与实验；庭院仍未交付。

原生色彩显示算子包含线性显示、sRGB 与旧 PBR 的 gamma 兼容档。原 HTML 颜色实验保留为 CPU 原理说明，不冒充 GPU 实验。正式 PBR、IBL、透明页的运行源码均已改为实际 WGSL。

本轮没有完成 32 篇文章、7 份基础说明，也没有移除全部 WebGL2 后端。阶段状态必须保持如实。

最终本地核对：49 个路由与 111 个内部链接/锚点通过；三个原生后端设备丢失重试通过。离屏曝光修改不再提交绘制命令，重新可见时恢复显示；快速异步检查后销毁的资源登记归零。PBR 配对最大位置差 0、法线分量差 7.45e-8、归一化辐射度差 2.98e-8，限于记录中的 30 个配置点，不是全场景误差界。最终构建通过，Astro/TypeScript 零错误、零警告。

P1 本批完成：阴影 GPU/CPU 27 组与原 13 项交互回归；CSM 18 个实际点的选择/权重；HDR 6 组含非零 Bloom 的合成核对，以及常量/脉冲的提取和两方向滤波。新增两篇各有完整正文、三个任务、WGSL 源码和静态预览。新任务的暂停单步、低档手机、键盘、无脚本与无 WebGPU 回退通过。当前 17 篇文章、3 份基础说明、12 个实验室；旧十个实验室中四个完成迁移。

本批单元测试 121 项，静态构建 54 页，导航检查 120 个内部链接/锚点。CSM/HDR 目前是分别可验证的实验；庭院、法线贴图和组合场景未完成，P1 仍标为进行中。人工试读仍待执行。
